SYNTRA

🌟 Descripción del Proyecto

Syntra es una aplicación móvil nativa para Android diseñada específicamente para mujeres que entrenan regularmente, ya sea en el gimnasio o en casa. Su objetivo principal es revolucionar la planificación, el seguimiento y la mejora del entrenamiento, integrando de manera inteligente la información del ciclo menstrual.

Con Syntra, las usuarias pueden optimizar su rendimiento físico, entender mejor su cuerpo y mantener un control detallado de su progreso, todo ello respaldado por un enfoque personalizado y basado en datos.

✨ Características Clave

Rutinas Personalizadas: Accede a planes de entrenamiento adaptados a tus fases hormonales y objetivos específicos.

Seguimiento del Ciclo Menstrual: Registra tu periodo para obtener recomendaciones de entrenamiento y nutrición ajustadas a cada fase (folicular, ovulatoria, lútea, menstrual).

Visualización de Fatiga Muscular (SVG): Observa de forma interactiva qué músculos han sido trabajados y su nivel de fatiga mediante un modelo anatómico interactivo.

Registro Detallado de Medidas Corporales: Controla tu peso, medidas, pliegues cutáneos y otras métricas avanzadas con gráficas interactivas.

Estadísticas de Rendimiento: Analiza tu progreso semanal con resúmenes de calorías quemadas, repeticiones, cargas levantadas y más.

Sugerencias Inteligentes (IA básica): Recibe recomendaciones automáticas de peso, RIR (Repeticiones en Reserva) y repeticiones basadas en tu historial y fase del ciclo.

Gestión de Perfil: Personaliza tu perfil, incluyendo la posibilidad de cambiar tu avatar.

Modo Claro/Oscuro: Elige tu tema visual preferido (claro, oscuro o automático).

Red Social Básica: Conéctate con otras usuarias para motivación y apoyo.

🚀 Tecnologías Utilizadas

Syntra ha sido desarrollada utilizando un stack tecnológico moderno y robusto para asegurar una experiencia fluida y escalable:

Jetpack Compose: Para el diseño de interfaces de usuario reactivas y modernas en Android.

Firebase: Utilizado para autenticación (Firebase Authentication), base de datos en tiempo real (Firebase Realtime Database), almacenamiento y notificaciones push (Firebase Cloud Messaging).

Vico: Librería para la creación de gráficos interactivos y visualizaciones de progreso.

SVG Renderer personalizado: Para la visualización anatómica de la fatiga muscular.

Retrofit: Para la integración con APIs externas (ejercicios, noticias de salud, sugerencias de comidas).

Clean Architecture (MVVM): Implementación de una arquitectura limpia para una separación clara de responsabilidades y modularidad del código.

⚙️ Instalación y Uso

Para instalar y ejecutar Syntra en tu dispositivo Android, sigue estos pasos:

Habilitar "Orígenes Desconocidos": En la configuración de seguridad de tu dispositivo Android, permite la instalación de aplicaciones de fuentes desconocidas. (Los pasos exactos pueden variar según la versión de Android).

Descargar el APK:

Visita el repositorio de GitHub: https://github.com/juliadelmar/Version00

Navega a la sección app/release/ y descarga el archivo .apk más reciente (ej. app-release.apk).

Instalar la Aplicación: Abre el archivo .apk descargado en tu dispositivo y sigue las instrucciones para instalar Syntra.

Iniciar la Aplicación: Una vez instalada, abre Syntra. Podrás registrarte con un nuevo usuario o iniciar sesión si ya tienes una cuenta.

📂 Estructura del Proyecto

El proyecto sigue los principios de Clean Architecture, organizando el código en capas bien definidas (dominio, datos, presentación) para una mayor mantenibilidad y escalabilidad. La inyección de dependencias se gestiona con Hilt.
